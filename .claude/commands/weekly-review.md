---
description: Prepare the weekly supplier programme review from spend, evidence exceptions and actions.
---

Run `npm run diversity -- participation --json`, `npm run diversity -- exceptions --json`, and `npm run diversity -- attention --json`. Read `imports --json` to identify the declared scope. Keep every currency separate. Report internal evidence coverage, missing certificates, overdue reports and the owner of each next action. Commitments are separate from payments. Unknown coverage is not zero spend. Run `draft-review` for the selected programme to a new filename under drafts. Never send or file a statutory return.
